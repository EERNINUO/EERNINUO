## 关于我
我做仪器，也做仪器背后那件事：把物理量变成可追溯的数字。

比起写漂亮的代码，我更喜欢弄清楚**一个信号从哪来、在哪变形、在哪丢**。

模拟前端、FPGA、MCU、协议、上位机、测试脚本——我喜欢把它们一个人串起来，因为只有串起来，才看得见系统真正的样子。

## 我最近在做

### [ArbWave30](https://github.com/EERNINUO/ArbWave30) · 30MHz 任意波形发生器
> 起因很简单：买不起，所以自己做。

FPGA + 高速 DAC + 模拟前端 + SCPI，目标是一台**诚实、可复刻的开源仪器**。

- 波形：正弦 / 方波 / 三角 / 噪声 / 直流，正弦最高 30MHz
- 7 阶椭圆滤波模拟前端，48 位相位累加 DDS
- USB CDC + SCPI-1999，可用 PyVISA 做自动化

*当前状态：开发中，MVP Release 在路上。*
